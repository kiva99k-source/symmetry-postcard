# 대칭 엽서

꽃잎 수 4~16개를 선택하고 회전대칭을 탐구하는 수학 수업용 웹페이지입니다.

별명과 작품 제목을 바꾸면 SVG 엽서가 즉시 갱신됩니다. 회전각 설명, 중심 안내, 한 칸 회전 시연, SVG 저장을 제공합니다. 외부 AI API나 빌드 과정은 필요하지 않습니다. 가상의 별명만 사용하며 편집 입력을 서버에 저장하지 않습니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 선택합니다. Branch는 main, 폴더는 / (root)를 지정하고 Save를 누릅니다. 배포가 완료되면 Pages에 표시되는 사이트 주소로 접속합니다.

수정 시 index.html을 교체하고 커밋하면 다시 배포됩니다.

## 수학

같은 꽃잎 n개를 중심 O 둘레에 360°/n 간격으로 놓으면 꽃무늬의 최소 양의 회전각은 360°/n입니다. 이 성질은 글자나 테두리를 포함한 엽서 전체가 아니라 꽃무늬에 해당합니다.
